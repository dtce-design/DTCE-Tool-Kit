quantities remain visible as unassigned until a matching pay item is provided.
Its subgrade unit is cu.m.; select sq.m. only for an appropriate target item.

that template. Missing variants remain unassigned rather than use ordinary.
A linked workbook retains its own descriptions; the original duplicate tree
label must be corrected there if it has not already been corrected.
