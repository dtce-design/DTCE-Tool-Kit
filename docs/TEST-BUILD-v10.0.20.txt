PATCH - open a saved project at the start (owner: "Pwede ba kapag maginsert ako project info magoopen na din yung project?"; "Sa start na
lang magoopen ng saved file tapos doon na din magsasave. Nakasave na din doon yung project"):
- Workspaces window: new "Open saved project" button beside Workspace settings. It opens a saved Bill of Quantities file (*.boq.xml,
  older *.pow.xml). The project information saved in the file becomes the current project (no need to fill in Project Information
  again), and the Bill of Quantities workspace opens with that file.
- Save (and Ctrl+S) in the Bill of Quantities then writes back to the same file, project information included; Save As still asks.
- A file without complete project information opens the Project Information window first, with a note.
