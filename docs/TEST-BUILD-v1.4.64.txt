DTCE Tool Kit v1.4.64 — NSCP 2015 beam deflection, DTCE watermark, 7pt reports (16 November 2026)

Builds on v1.4.63 (see TEST-BUILD-v1.4.63.txt).

1. BEAM DEFLECTION CHECK PER NSCP 2015
- Each beam row selects an NSCP 2015 criterion instead of a free L/n:
  Reinforced concrete — Table 424.2.2:
    Row 1 flat roof, no damageable nonstructural elements: immediate roof live load ≤ L/180
    Row 2 floor, no damageable nonstructural elements: immediate live load ≤ L/360
    Row 3 roof/floor supporting damageable elements: after attachment ≤ L/480
    Row 4 roof/floor supporting non-damageable elements: after attachment ≤ L/240
  Steel / other — NSCP Chapter 1 member limits: floor L/360 (L), L/240 (D+L); roof with plaster ceiling
    L/360, L/240; nonplaster ceiling L/240, L/180; no ceiling L/180, L/120. Cantilever: L = 2 × length.
  Custom L/n (project specification) remains available.
- Dead/sustained and live STAAD cases are entered separately and superposed node by node.
- RC time-dependent deflection: λΔ = ξ/(1+50ρ') (Section 424.2.4.1.1), ξ from Table 424.2.4.1.3
  (sheet setting: 5 years+, 12, 6, 3 months). After attachment = λΔ·δD,i + δL,i (conservative: all
  sustained load assumed after attachment).
- Cracking: immediate deflections × Ig/Ie when STAAD uses gross stiffness. New "RC Ie calculator"
  (Section 424.2.3.5, Eq. 424.2.3.5a): Ec = 4700√fc', fr = 0.62λ√fc', Mcr = fr·Ig/yt, cracked
  transformed section with compression steel, Branson Ie ≤ Ig. Fills Ig/Ie and ρ' for the selected
  row; the report reproduces the derivation and flags edited values that differ from it.
- Report: NSCP criteria tables, parameters per beam (ξ, ρ', λΔ, Ig/Ie), summary, node tables with
  δD, δL and each check, substitution at the governing node, governing deflected shape.
- Saved sheets from v1.4.63 open as Custom-limit rows (their cases become live cases).
