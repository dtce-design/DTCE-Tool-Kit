MAJOR - new design sheet "Load Combinations (NSCP 2015)" (owner: "create load combinations for superstructure including orthogonal
effect for staad input"; "no included in Earthquake Sheet - Load Combinations NSCP 2015"; "LOAD ComBo No. Start 1000, 2000, 3000, 4000,
5000, 6000 per group"; "use standard naming same as input on staad"; "Seismic-H is the Load Type"; "Title EQ+X EQ-X etc... DL, LL, LLR,
WL"; "hiwalay yung LL1 at LL2 yung f1 niya"; the STAAD notes A / B / C; "depende kung gaano kadami input sa Primary Loads"; "also for drift
check wind and seismic"):
- Primary loads: paste the STAAD primary load cases (LOAD 5 LOADTYPE SEISMIC-H TITLE EQ+X, or 5 EQ+X Seismic-H). The load type gives
  D (Dead), L (Live), Lr (Roof Live), W (Wind), Eh (Seismic-H / Seismic, or None with an EQ title), Ev (Seismic-V); without a type the
  title is read (DL, SDL, LL1, LL2, LLR, WL+X, EQ+X ...). The number of combinations follows the number of primary cases.
- Combinations, titled with the STAAD titles (1.2DL+1.6LL1+1.6LL2+0.5LLR) and numbered by group:
  1000 LRFD gravity, 2000 LRFD wind, 3000 LRFD seismic (NSCP 2015 203.3.1), 4000 ASD gravity, 5000 ASD wind, 6000 ASD seismic (203.4.1),
  7000 wind drift (D + 0.5L + 0.6W, factor editable), 8000 seismic drift (1.0 Eh of every seismic case, Section 208.6.4).
- f1 per live case: the live cases listed get f1 = 1.0 (assembly, over 4.8 kPa, garages), the others 0.5.
- E = rho Eh + Ev (208.5.1.1); Ev = 0.5 Ca I D in the dead load factor (or the Seismic-V case); ASD uses E / 1.4.
- Structure (seismic cases), as in the owner's STAAD notes: A regular and symmetrical (EQ +X, -X, +Z, -Z each alone); B regular and
  unsymmetrical (EQ +X +E ... with accidental torsion, each alone); C irregular and unsymmetrical (orthogonal effects: eight load cases
  1.0(EQ +X)+0.3(EQ +Z) ... written as REPEAT LOAD, Load Type Seismic, numbered after the primary loads, then used in the combinations).
- Output: the STAAD text (lines within 72 columns), tables of the cases and combinations, and a report.
- Access: its own program 16384 - added to the desktop Access Code Generator, the web generator (mobile/) and the iPhone app (ios/);
  uploading those (Pages / TestFlight / App Store) needs its own request.
Tests: StaadCombinationsTests 22.
