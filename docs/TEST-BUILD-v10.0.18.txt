- Design sheets: Ctrl+S saves (the first time it asks for the file, then saves to the same file without asking), Ctrl+Shift+S saves
  as a new file, Ctrl+O opens. The Save sheet XML button works the same way. The five Design Loads sheets share one file, so Ctrl+S
  in any of them saves all five. The status bar shows where it was saved.

  across the ridge: windward E long wall"). The other assessed directions follow, marked "REFERENCE, NOT A FACE" (diagonal wind /
  Kzt envelope). With a ridge azimuth that is not a multiple of 45 degrees the eight directions already turn with the building (v7.2.37).
