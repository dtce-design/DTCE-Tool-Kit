DTCE Tool Kit v1.32.0 test build (19 November 2026)

Not tested on Windows yet (Linux/Mono checks only). GitHub test build, not a Microsoft
Store release (the Store still has v1.5.0).

Construction Schedule ("hindi ba pwede paiksiin yung working days")
- Double-click an item in the Bar Chart to set the number of crews working on it at
  the same time. The output per hour stays fixed at the DUPA value ("fix yung output
  per hour"). No. of days = quantity / (output per hour x 8 hours x crews), rounded up.
  The dialog shows the new duration before it is applied; Reset returns to 1 crew. More crews add their workers to the daily manpower. The choice is saved with
  the Program of Works, and the PDM, PERT-CPM, manpower and printed set follow it.
- The longest items are usually painting, ceilings and tiles; adding crews there
  shortens the critical path the most.

Reports ("wala naman pinagbago ang detailed at extensive")
- Detailed and Extensive gave the same PDF report. Extensive now adds, after the
  Detailed calculation record, a calculation trace of every bar (pieces x cut length x
  unit mass = cut steel, lap and offcut, commercial bars and segments used) and, in the
  Program of Works report, the commercial bars to order. Beam and slab estimate reports
  get the same trace.

Bill of Quantities
- A quantity left unmapped by hand stays unmapped even when the app has its own pay item
  for it.
