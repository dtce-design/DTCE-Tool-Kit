Construction Schedule ("hindi ba pwede paiksiin yung working days")
- Double-click an item in the Bar Chart to set the number of crews working on it at
  the same time. The output per hour stays fixed at the DUPA value ("fix yung output
  per hour"). No. of days = quantity / (output per hour x 8 hours x crews), rounded up.
  The dialog shows the new duration before it is applied; Reset returns to 1 crew. More crews add their workers to the daily manpower. The choice is saved with
  the Program of Works, and the PDM, PERT-CPM, manpower and printed set follow it.
- The longest items are usually painting, ceilings and tiles; adding crews there
  shortens the critical path the most.
