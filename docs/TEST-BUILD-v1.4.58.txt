DTCE Tool Kit v1.4.58 — large workbook attachment fix (16 November 2026)

Removed fixed attachment size, total-size and file-count limits. Original Excel,
DXF and reference files are copied into a disk-backed cache with a bounded 64 KiB
buffer and SHA-256 verification. Full POW saves stream compression/base64 directly
to the atomic output file. Opening POW streams original attachments back to disk
instead of loading their payloads into the calculation XML document. Saving and
opening retain the existing .pow.xml format and legacy source-archive compatibility.
There is no app-imposed attachment size/count ceiling; available disk space and
system resources are the practical limit. Temporary original copies remain local
and are cleaned up on normal process exit. Preserve the saved POW, not this cache.

Selected Excel workbook capture runs in the background. An original-copy IO/access
failure produces a separate attachment notice and does not itself pause or prevent
Excel linking/sync. Actual Excel connection failures remain errors. Original copies
are snapshots from link time; the live workbook remains a separate file.
Map BACKUP items currently requires a live linked Excel workbook with a BACKUP
sheet. A saved list of 266 pay items does not indicate a live connection.
