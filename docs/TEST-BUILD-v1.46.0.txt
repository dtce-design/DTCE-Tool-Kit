DTCE Tool Kit v1.46.0 test build (19 November 2026) - not pushed (owner: "huwag mo munang ipush")

Not tested on Windows yet (Linux/Mono checks only). Not a Microsoft Store release.

Earthquake Load tab ("sa design sheet gumawa ng sub tab for Earthquake Load, input coordinates determine nearest
active fault, determine Seismic Source Type. ilagay ang historical records ng earthquakes"; "For fault line check
phivolcs"; owner chose the automatic HazardHunterPH look-up)
- The design sheet is now "Earthquake Load & RSA Curve Builder" with a first tab, Earthquake Load.
- Enter the site coordinates and press Look up site (internet needed; one request per press):
  - nearest active fault with distance and direction, ground rupture, ground shaking intensity, liquefaction and
    the site location from HazardHunterPH (DOST-PHIVOLCS / GeoRiskPH) - the same point assessment as their site;
  - historical earthquakes within the chosen radius, minimum magnitude and start year from the USGS ANSS
    Comprehensive Catalog, largest first, with distance from the site.
- Seismic source type per NSCP 2015 Table 208-3 from the fault's Mmax and slip rate. Suggested values are filled
  in for the Philippine Fault Zone and the Valley Fault System (marked "suggested - verify"); for other faults
  enter Mmax and slip rate from PHIVOLCS. The distance and source type are copied to Site and structure, so Na,
  Nv and the spectrum follow.
- The look-up results are saved with the sheet (work offline afterwards) and appear in the calculation report
  with their sources and retrieval date.

Includes v1.45.0 and earlier local builds (see their notes).
