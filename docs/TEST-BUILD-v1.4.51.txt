  before replacing the destination. Printing allowed; editing, copy/extraction,
  annotation, form changes and page assembly restricted. No weaker fallback.
  A missing/damaged security component stops export and preserves the destination.

SECURITY LIMITS
PDF permissions depend on the reader. An open/printable PDF cannot be guaranteed
immune to alteration: tools can ignore restrictions, printed output can be captured
or reprinted, and images can be reconstructed/OCR'd. Modern PDF encryption permits
accessibility extraction by specification; flattened app pages contain no selectable
text layer. This build does not add a certificate signature or claim tamper-proofing.
HTML/Excel source/report exports remain separate formats, not protected PDF files.

INSTALLATION / TESTING
Extract the complete DTCE-Tool-Kit-Admin-v1.4.51 folder before running the EXE.
Keep tools/qpdf and its DLLs/licenses with the application. Windows x64 and .NET
Framework 4.8 are required. Use existing authorized activation/owner keys; no private
key is bundled. Settings/profile storage remains under the Windows user account.
