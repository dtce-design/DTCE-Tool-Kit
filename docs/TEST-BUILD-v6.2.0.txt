DTCE Tool Kit v6.2.0 test build (22 November 2026) - not uploaded to the Microsoft Store (v6.0.48 is the last requested upload).

MINOR (new features):
- Formatters (Beam, Slab, Column): "Detailing / schedule" option - DTCE standard (Ø bars) or ACI 318M / SP-66 (# bars)
  (owner: "Add an option sa formatters to use aci detailing and schedule"; the shared ACI Detailing Manual could not be read here, the
  owner chose the typical ACI conventions). ACI: bar sizes as #16 (16 mm bar), spacing in ACI wording ("automatic convert the
  standard naming of spacing of ties"): beam stirrups "1 @ 50, 15 @ 75, REST @ 125", slab bars "#10 @ 175 O.C.", column hoops
  "#10 @ 75 O.C. (Lo = 585)" / "#10 @ 200 O.C. REST", and ACI 318M-14 detailing notes under the schedule (hooks 25.3, Class B laps
  25.5.2, beam hoops 18.6.3.3 / 18.6.4.4, bar extensions 9.7.3.8, slab spacing 7.7.2.3 / 8.7.2.2 / 24.4.3.3, column Lo, hoop spacing
  and laps 18.7.4.3 / 18.7.5.1 / 18.7.5.3, joint hoops 18.8.3.1). The ACI files read back in the Bar Bending Schedule as before.
- Bill of Quantities > Column Estimate > Load column schedule DXF ("yung revised sa formatter kaya din iestimate sa boq"): the Column
  Formatter output (or the RCDC original) fills Manual column schedules - one type per mark and level range: section, two bar groups,
  tie size, the tie schedule "1 - 50mm, n - s1mm, AND REST AT s2mm C/C" covering Lo, inner links as two open ties per set and
  crossties as one - and one Column Estimate row per mark (full height, quantity = identical columns), taken off per level.
- Column Formatter: a different confining zone Lo alone no longer gives another mark ("minerge yung identical column pero di naman
  nag assign ng single column mark"); the group shows and uses the largest Lo of its columns at each level (owner file: 34 > 9 marks).
Checked on Linux/Mono only (the Bill of Quantities recalculation itself cannot run under Mono; verify the column take-off on Windows).

Includes v6.1.0 and earlier builds.
