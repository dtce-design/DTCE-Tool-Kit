  suggestion under it); 3 STAAD model (one choice: +X along the ridge toward the azimuth / the opposite way, or across the ridge

  typed +X bearings and the separate ridge-axis choice. Only inputs that apply are shown (G only when not calculated, damping /
  frequencies only when calculated, qi height only for partially enclosed buildings); nothing below the switch shows while building
  pressures are off.
- Older sheets open converted: a compass alignment becomes its azimuth; a compass / typed +X with the ridge axis becomes the azimuth and
  the +X choice; STAAD X / Z dimensions become the width and length.
- Fixed: the 3D building model and the report text followed only the compass alignment, not a typed azimuth; both use the azimuth now.
