DTCE Tool Kit v1.30.1 test build (19 November 2026) - bug fix

Not tested on Windows yet (Linux/Mono checks only). GitHub test build, not a Microsoft
Store release (the Store still has v1.5.0).

Program of Works - Bill of Quantities mapping (owner: "nawawala yung mapping kapag
naglink or open na ako ng excel")
- Linking or opening a BACKUP workbook kept the saved mapping only when the item no.,
  description and unit matched exactly. A mapping made on the app's own catalogue, or
  on a workbook with other wording (for example "Painting Works, Metal" against
  "Painting (Metal)", "1032 (1) c" against "1032(1)c", "sq.m." against "m2"), was lost.
- The saved mapping now follows its item by the exact item no., description and unit
  first, then by item no. and unit, then by description and unit, then by item no.
  alone - each only when it names exactly one BACKUP item. Items still not found are
  listed in a message, never moved to a different item.
- Typed BOQ quantities follow their item the same way (linking no longer stops with
  "Saved manual pay item is missing or ambiguous" when only the wording differs).
