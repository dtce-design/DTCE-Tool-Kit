DTCE Tool Kit v1.8.0 test build (18 November 2026)

Finishing Works, simplified (owner: "sa Start mag-assign lang ng Finishing ID,
description, tapos anong group siya sa BOQ"; "sa wall/ceiling/floor may Finish ID
doon na ise-select; sa Start i-consolidate niya lahat per group")
1. Start > Finish Schedule: Finish ID, Description and "BOQ pay item / group".
   Click the third column to choose the BACKUP pay item (when a BACKUP
   workbook is linked); the group takes the pay item's name and its areas go
   straight to that item in Bill of Quantities - no separate mapping step.
   Before linking, a group name can still be typed.
2. Wall / Ceiling / Floor Finishes: choose the Finish ID on each measured
   row (v1.7.0).
3. Start > lower table is now TOTALS PER GROUP: one line per group with its
   Finish IDs, the measured entries (Wall / Ceiling / Floor and their IDs),
   the total area and the BOQ item it goes to ("Not mapped yet" otherwise).
   It replaces the Assign Finishes list.

Includes v1.6.0-1.7.0. Not a Microsoft Store release (v1.5.0 is the Store build).

Standard finish groups with item numbers (owner list, "ilagay din yung item no.")
- Clicking the group column offers the 35 standard finish groups with their
  BACKUP item numbers (1016(1)a Two-Component Cementitious Waterproofing ...
  1032(5) Textured Finish). The Finish Schedule and the totals table show
  "item no. | name" (e.g. "1021(5) | Cement Broom Finish").
- A standard group is routed to its pay item automatically in Bill of
  Quantities (item no. + description), so no separate mapping is needed.
  Other typed group names still work and can be mapped as before.
